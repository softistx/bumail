The first release of `@bumail/mime`: read and write e-mail messages with no dependency — RFC 5322 headers, addresses and dates, RFC 2047 encoded-words, RFC 2231 parameters, MIME multipart, base64 and quoted-printable, charsets through `TextDecoder`, a streaming parser in bounded memory, and a builder that writes 7-bit messages ready for SMTP.
